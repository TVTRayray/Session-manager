# Visual QA Checklist: <project-name>

> 由设计宪章推导的机械验收清单。QA 对 Design Impact ≠ none 的 change 必须逐条执行，
> 结果写入 QA Report 的 Design Conformance 节。不合格退回 Coder 并附截图证据。

## 一致性

- [ ] 所有窗口/表面使用同一 token 体系（grep 无组件内硬编码颜色/圆角）
- [ ] 强调色、圆角、字体全应用一致

## 主题与对比度

- [ ] 明/暗双模关键面截图对比，无反色/低对比错误
- [ ] 正文对比度 ≥ 4.5:1（WCAG AA），大字号 ≥ 3:1
- [ ] 主题切换即时生效，无白闪/跳变

## 字体与圆角

- [ ] 声明字体真实加载（非系统回退）
- [ ] 圆角规则全应用，无规则外圆角

## 动效与无障碍

- [ ] 动效有动机（层级/叙事/反馈/状态转换四类之一）
- [ ] prefers-reduced-motion 下全部瞬时
- [ ] 焦点可见（focus-visible），键盘全程可操作

## 状态完整性

- [ ] loading / empty / error 状态齐全且指引明确
- [ ] 信息密度符合宪章上限

## 隐私与安全（视觉侧）

- [ ] 无正文泄露面（如敏感内容遮挡有效）
- [ ] 日志/提示不含查询词或正文

## 回归

- [ ] 键盘语义无回归（快捷键/Esc/焦点）
- [ ] 设置持久化走后端契约（非 localStorage 真相源）
