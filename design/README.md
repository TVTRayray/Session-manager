# TUI 界面设计稿（配套 docs/prd-7.md）

本目录是 `docs/prd-7.md` 的前端界面设计产出，用于在编码前把新增功能（收藏/标签、Markdown 导出、全文搜索、项目 Dashboard）落成可指导开发的界面示意图。**不涉及代码实现，也不修改 `docs/prd-7.md`。**

## 方法论

工具是纯终端 TUI，没有图形界面，因此这里的"示意图"采用 **ASCII 线框图 + Mermaid 状态图**，而不是图片原型。所有线框图以当前已安装、正在使用的 sessions-manager 界面为基准（引擎 Tab、树状分组列表、Detail 面板、Group Summary 卡片、Delete/Help 弹窗、状态栏两段式布局、Catppuccin Mocha 配色），在其之上叠加 PRD-7 规划的新元素，尽量保持视觉语言一致，而不是另起一套风格。

线框图统一以 **130 列 × 40 行** 作为参考尺寸（实际运行时由现有的动态布局引擎重排，不代表最小可用尺寸）。

## 阅读方式

* 线框图中方括号 `[ ]` 或普通文字标注是**说明性文字**，真实渲染内容都放在代码块里，尽量贴近实际字符宽度。
* 每份新界面文档末尾都列了"待确认问题"——这些是设计过程中做出的合理假设，建议开工前和你对一遍，避免实现完才发现方向不对。
