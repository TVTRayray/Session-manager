# 02. 收藏 / 标签（对应 PRD-7 第 2 节）

## 目标
在不改变现有双栏骨架的前提下，让收藏状态和标签在列表里"一眼可见"，并能通过既有搜索框直接过滤。

## 1. 列表行视觉变更

在现有叶子节点格式基础上，**前置收藏星标**、**后置标签徽标**：

```text
╭ Sessions (By Time) ─────────────────────────╮
│▾ 🕒 2026-09-16 (4 main · 27 sub)             │
│    ★ [python-script] 新彭楠-备煤日进及消…  #bug #紧急 │
│      ↳ Explore · 子代理探索任务                │
│  🕒 2026-09-15 (2 main · 3 sub)              │
│▾ 🕒 2026-09-14 (1 main · 0 sub)              │
│      [demo-repo] 修复登录态过期问题  #重构     │
╰────────────────────────────────────────────────╯
```

* `★` 只在收藏时出现（未收藏不占位，不引入对齐空格，保持现有列表紧凑感）。
* `#tag` 用弱化色（THEME_MUTED）追加在摘要之后；标签过多时按可用宽度截断，末尾加 `…`。
* 子代理/子会话节点（`↳` 开头）**不显示**收藏星标和标签——收藏/标签只作用于主会话粒度，避免树状节点进一步拥挤。

## 2. 新增分组模式：按标签分组

沿用现有 `g` 键循环切换分组模式，新增第三档：

```
By Time → By Project → By Tag → (循环回 By Time)
```

按标签分组时，分组图标使用 `🏷️`，未打标签的会话归入固定分组 `未分类`：

```text
╭ Sessions (By Tag) ───────────────────────────╮
│▾ 🏷️ bug (3 main · 5 sub)                     │
│    ★ [python-script] 新彭楠-备煤日进及消…      │
│  🏷️ 重构 (1 main · 0 sub)                     │
│▾ 🏷️ 未分类 (12 main · 40 sub)                 │
╰──────────────────────────────────────────────╯
```

一个会话有多个标签时，会在每个对应标签分组下各出现一次（树状视图允许同一 session_id 出现在多个父节点，不做去重合并）。

## 3. 搜索框语法扩展

复用现有 `/` 输入框（不新增 UI 元素），在既有关键字匹配逻辑前先解析特殊前缀：

| 输入 | 效果 |
| :-- | :-- |
| `fav:` | 只保留收藏的会话 |
| `tag:bug` | 只保留标签包含 "bug"（子串、不区分大小写）的会话 |
| `tag:bug 登录` | 先按标签过滤，再在结果内按 "登录" 做普通关键字匹配 |

搜索提示行的空输入占位文案同步更新，提示用户这个新语法（例如 `[type to search, or fav: / tag:xxx]`）。

## 4. 快捷键

| 按键 | 功能 | 生效范围 |
| :-- | :-- | :-- |
| `f` | 切换当前选中会话的收藏状态 | 列表聚焦叶子节点时 |
| `t` | 打开标签编辑弹窗（见 `03-tag-edit-modal.md`） | 列表聚焦叶子节点时 |

在 Group Header 上按 `f`/`t` 不生效（收藏/标签是会话粒度的操作），保持静默无反应，不报错。

## 5. 待确认问题

* 标签是否需要预设颜色/分类（如 `bug` 用红色、`feature` 用绿色），还是统一用一种弱化色？本设计默认统一配色，避免用户需要额外管理"标签颜色映射"。
* 多标签排序：按输入顺序，还是按字母序固定？建议按用户输入顺序展示，便于用户自己组织优先级。
