# 06. 项目 Dashboard（对应 PRD-7 第 5 节）

## 定位
复用现有双栏骨架，**不新增整屏视图**——右侧 `Detail` 面板在 Dashboard 模式下替换为统计卡片（对应代码里新增 `RightPanelMode::ProjectDashboard`，与现有 `GroupSummary`/`SessionDetail` 并列）。左侧列表面板保持不变，方便用户在浏览 Dashboard 的同时仍能切换项目。

## 触发
在"按项目分组"模式下，光标停在某个项目 Group Header 时按 `D`（大写，与删除 `d` 小写区分，避免误触）。

## 指标说明（对应 PRD-7 5.3 节 MVP 范围）

| 指标 | 数据来源 |
| :-- | :-- |
| 会话总数（按引擎细分） | 现有 `SessionListItem` 按 `cwd_group_label` + `engine` 聚合 |
| 收藏数 / 常用标签 | `02-favorites-tags.md` 引入的 `state.db` |
| 最近活跃 | 现有分组已有的 `last_active` 字段（`GroupSummaryCard` 已有同名概念） |
| 正文总量 | 全文搜索索引（`04` 文档）产出的统计；索引未完成时该数字标注"部分会话未索引"，不报错、不阻塞 |
| 最近会话列表 | 该项目下按时间倒序取前 N 条，用于快速跳转 |

**明确不包含**（PRD-7 已取消/明确排除）：Git 提交信息、时间趋势折线图等复杂可视化。

## 交互

| 按键 | 行为 |
| :-- | :-- |
| `↑` / `↓` | 在"最近会话"列表中移动选择 |
| `Enter` | 跳转到选中会话的详情视图（左侧列表同步选中该节点，右侧切回 `SessionDetail`） |
| `Esc` / `q` | 退出 Dashboard，返回该项目的 `Group Summary` 卡片 |
