# UX Design: efficiency-export-search-dashboard

## Design Impact

- 档位：`visual`
- 关联宪章条目：
  - **终端一致性与无闪烁体验**：所有浮层与模态均采用 `ratatui::Clear` + 边框遮罩，层级清晰，渲染无闪烁与布局抖动。
  - **模态互斥保证**：全局至多存在一个活动浮层，避免多层弹窗嵌套带来的按键劫持与认知负荷。
  - **零外置图表与纯文本表达**：统计数据采用纯 ASCII/Unicode 字符渲染，不引入图形或三方图表库。
  - **窄终端与超小屏幕自适应**：在宽度小于 80 字符或高度小于 24 行的极端终端下，降级折叠或截断次要信息，保证核心信息可读与按键可用。

---

## 视觉意图

- **一句话目标**：在不破坏现有双栏骨架与键盘流的前提下，为单会话/分组提供无感确定的导出反馈，为跨引擎全文检索提供高密度片段浮层，并为项目维度提供清晰直观的纯文本统计 Dashboard。
- **与现状的差异**：
  - 导出操作由“无导出”升级为“单会话即时状态栏反馈”与“分组二次确认弹窗 + index.md 清单”；
  - 搜索操作从单一的“`/` 元数据单行过滤”升级为“`/` 保持原状 + `Ctrl+F` 全文多行正文片段浮层”双轨并行；
  - 右侧面板从仅有 `SessionDetail` 和 `GroupSummary` 两档，扩展出专属的 `ProjectDashboard` 统计与最近会话视图。

---

## 受影响表面

1. **状态栏（Status Bar）**：
   - 常规消息区：展示导出完成绝对路径（`⚡ Exported to ...`）或错误提示（`⚡ Export failed: ...`）。
   - 索引进度指示：展示后台 FTS 构建进度（如 `[索引中 42/128 会话]`），构建完毕后自动隐去。
2. **全文搜索全屏浮层（Full-text Search Overlay）**：
   - 触发键：`Ctrl+F`，居中比例约为 84% 宽 / 80% 高（最小尺寸 60×16，超大终端宽度上限 120 列）。
   - 包含常驻搜索输入行（🔍 图标）、防抖实时结果列表（单行摘要 + 命中片段高亮 + 更多匹配折叠）、底部常驻索引状态与快捷键导航指南。
3. **批量导出确认弹窗（Batch Export Modal）**：
   - 触发键：在 Group Header 上按 `e`。
   - 居中紧凑对话框（约 50×10），包含分组名称、将导出的会话数量、`[ Cancel ]` 与 `[ Export ]` 焦点切换按钮。
4. **项目 Dashboard 面板（Project Dashboard）**：
   - 触发键：在 `By Project` 模式下光标停在项目 Group Header 按 `D`。
   - 占据右侧详情面板空间，分为上半区指标汇总（ASCII 表格与字符进度条）与下半区“最近会话”列表。
5. **帮助浮层（Help Modal）**：
   - 增补 `e`（Export to Markdown）、`Ctrl+F`（Full-text search）、`D`（Project dashboard）快捷键说明。

## 关键状态与边界保护

1. **窄终端保护（Terminal Width < 80）**：
   - 搜索浮层自适应占满可用宽度的 96%，单条结果内收缩 snippet 预览为 1 行并省略次要时间字段；
   - Dashboard 标签分布展示收缩为 Top 3，正文规模次级说明自动截断；
   - 状态栏长路径展示采用前缀截断保留末尾文件名。
2. **极端高度保护（Terminal Height < 20）**：
   - Dashboard 隐藏“最近会话”列表，仅保留核心指标面板；
   - 搜索浮层最大展示 3 条匹配结果，保证输入框与快捷键提示不被裁切。
3. **错误与降级状态**：
   - 导出只读目录：明确提示权限错误信息，内存与原文件状态保持原样；
   - FTS5 不可用：禁用后台索引线程，不卡顿、不重试，浮层给出明确原因；
   - 跳转失效会话：提示“会话已不存在”，视口重置，保持焦点稳定。

---

## 与宪章的符合性

- **轻量即时（Zero Bloat）**：单会话导出无打扰弹窗，仅在批量导出时做二次确认。
- **纯文本与无外部依赖（Pure Text）**：所有指标、边框、进度条均使用原生字符绘制，绝无外部图表组件引入。
- **安全可见（Security Visible）**：敏感查询关键词与正文内容绝不落盘与打印日志；导出路径严格做 containment 校验并在界面显示真实落盘绝对路径。

## 验收提示（给 QA）

1. **单会话导出**：在叶子节点按 `e`，检查状态栏是否显示绝对路径，校验对应目录文件是否存在，验证 Frontmatter 格式与 Markdown 章节映射。
2. **批量导出**：在 Group Header 按 `e`，弹窗聚焦 `[ Cancel ]`，按 `Tab` 切换到 `Export` 并按 `Enter`。验证导出目录下各 `.md` 文件及 `index.md` 清单。
3. **全文搜索高亮**：按 `Ctrl+F`，输入关键词，检查实时匹配与高亮；测试上下箭头选择与 `Enter` 跳转，验证是否正确定位至目标 block；测试 `Esc` 退出是否恢复此前列表焦点。
4. **搜索空状态与 Stale 容错**：输入不存在词验证无空白白屏；搜索命中后在外部手动删除会话文件，回车跳转验证是否友好报错且不 panic。
5. **Dashboard 指标与跳转**：在 `By Project` 模式下按 `D`，验证各引擎分布数之和是否等于总数，验证标签 Top 5 排序与出现频次，在下方面板上下选中回车跳转验证。
6. **模式互斥性**：在搜索浮层、删除弹窗、标签弹窗同时尝试触发其他快捷键，验证是否严格互斥。
