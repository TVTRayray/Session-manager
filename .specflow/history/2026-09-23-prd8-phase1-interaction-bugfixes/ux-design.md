# UX Design: prd8-phase1-interaction-bugfixes

> 产品设计工件。Design Impact: `visual`。
> 覆盖 PRD-8 Phase 1 的 F2 鼠标视口映射规范与 F3 宽字符/选中态渲染设计规范。

## Design Impact

- **档位**：`visual`
- **关联宪章条目**：
  - 界面稳定性与防闪烁/防残影原则：高亮与选中状态切换必须具备完全的幂等性与可逆性，禁止引起文字丢失。
  - 所见即所得交互原则：鼠标指针点击的视觉像素/字符行，必须精确命中对应的数据节点，视口滚动状态必须透明补偿。
  - 终端宽字符排版规范：CJK 全角字符占 2 列宽，变体选择符（VS16）不占额外宽度，结合标记不可孤立残留，图标与文本边界样式切换不得穿透字符内部。

## 视觉意图

- **本次变更要达成的视觉/体验目标**：
  消除列表滚动后鼠标点选错位的交互断层，杜绝反色选中态下图标截断与「🏷️ 未分类」中「未」字消失的渲染缺陷，确保 TUI 在各种终端（包括 Ghostty、Kitty、WezTerm 等）下的文字显示完整稳定。
- **与现状的差异**：
  - 现状：滚轮滚动列表后，点击视口某行会选中原本顶部位置的行；选中带有 emoji 的分组头再移开，汉字「未」永久消失；选中收藏行时 `★` 显示为半个残缺符号；极窄宽度截断可能切碎双列字符。
  - 变更后：滚动后点击即所见即所得；选中与取消选中状态任意切换，字符完整如初，图标饱满无残缺；结合标记与 Emoji 变体选择符正确对齐，极窄列宽下安全无崩溃。

## 受影响表面

- **窗口/组件/状态列表**：
  - 左侧会话树列表（`tui-tree-widget`，`TreeWidget` 面板）：普通行、选中反色行（`Modifier::REVERSED`）、滚动中与滚动后状态。
  - 会话树分组头：`ByTag` 模式下的 `🏷️ 未分类` 及普通标签头 `🏷️ [tag]`。
  - 会话叶节点行：收藏图标 `★`、标签前缀 `🏷️`、路径与摘要文本。
  - 鼠标左键点击事件捕获层（`src/app.rs::handle_mouse`）。
- **是否动 tokens**：否。完全沿用既有 Catppuccin 主题颜色 tokens 与反色样式修饰符。

## 交互与视觉设计规范

### 1. F2: 鼠标点击视口偏移映射规范

#### 视口行计算公式
列表面板在终端内的有效显示区域为：
- 顶部 y 起始：`layout.list_panel.y + 1`（扣除上边框）
- 底部 y 截止：`layout.list_panel.y + layout.list_panel.height - 2`（扣除下边框）
- 视觉可见行号 `visible_row`（0-indexed）：
  $$\text{visible\_row} = \text{event.row} - \text{layout.list_panel.y} - 1$$
- 映射到全局可见数据列表的真实索引 `data_index`：
  $$\text{data\_index} = \text{tree\_state.get\_offset()} + \text{visible\_row}$$

#### 行为与边界契约
1. **边界检查**：若 $\text{data\_index} \ge \text{visible\_tree\_identifiers.len()}$，说明点击了列表末尾下方的空白填充区域，系统安全忽略该事件（清除 path hint，不触发选中与详情加载）。
2. **零偏移不变性**：若从未进行滚轮操作（$\text{tree\_state.get\_offset()} == 0$），计算结果严格恒等于 $\text{visible\_row}$，与基线逻辑 100% 一致。
3. **滚动与点击交替操作**：滚轮滚动（上下每次步长 3）实时更新 `tree_state` 内部 offset；点击后紧接着滚动、或滚动后紧接着点击，不会引起累计误差。

### 2. F3: 宽字符与高亮渲染设计规范

#### 字符分类与列宽定义
| 字符 / 符号 | Unicode 码点 | 规范列宽 | 说明 |
| :-- | :-- | :-- | :-- |
| `★` (收藏) | U+2605 | 1 列（在 East Asian 终端排版与空格组合时保障 2 列槽位） | 避免反色边界拆分 |
| `🏷` (标签) | U+1F3F7 | 2 列 | 标准 Emoji 宽字符 |
| `️` (VS-16) | U+FE0F | 0 列 | 变体选择符，不可计入 1 列，否则引发光标错位 |
| 结合标记 (Combining Mark) | 如 U+0301 (acute) 等 | 0 列 | 依附前驱基字符，不可单独截断滞留 |
| `未` / `分` / `类` | U+672A / U+5206 / U+7C7B | 2 列 | CJK 全角汉字 |
| `📂` / `🕒` | U+1F4C2 / U+1F552 | 2 列 | 分组头图标 |

#### 高亮与 Span 组合规范
1. **统一整行反色安全**：
   在会话树节点被选中时，`tui-tree-widget` 对整个选中区域施加 `highlight_style`（`Modifier::REVERSED`）。
   - 图标与紧随的空白字符置于稳定的 Span 边界内部，禁止因单独 Span 的反色样式导致终端光标定位截断半个字符。
   - 变体选择符 `\u{fe0f}` 的列宽在内部 `display_char_width` 中识别为 0。
2. **结合标记截断规范**：
   - 当字符串截断边界遇到组合字符（如 `e\u{301}`）时，不得将 `\u{301}` 孤立留存在截断末尾，必须将基字符与结合标记视为不可分割单元进行列宽计算与截断。
3. **极窄列宽（0, 1, 2 列）安全契约**：
   - 0 列宽限制：输出空串 `""`，不越界。
   - 1 列宽限制：若首字符为 2 列宽汉字或 Emoji，安全输出空格或空串，严禁超宽输出 2 列内容，严禁 panic。
   - 2 列宽限制：容纳完整双列字符，不切碎。
4. **分组头状态幂等还原**：
   - 未选中态：`🏷️ 未分类 (X main · Y sub)`，前景色为 `THEME_HIGHLIGHT`，粗体。
   - 选中态：整行反色（高亮背景，反转前景色）。
   - 取消选中态：完全还原为初始样式与完整字符内容，严禁发生「未」字消失或字符残留。

## Before / After

### 场景 1：滚轮滚动后的鼠标点击定位 (F2)

**Before (缺陷):**
```text
[视口初始]                [滚轮下滚 4 行]               [鼠标点击视口第 1 行 "Session 5"]
1. Session 1             5. Session 5  <-- 视觉在第 1 行   ❌ 实际选中的却是 "Session 1"
2. Session 2             6. Session 6                     (因为代码直接按 visible_row=0 索引)
3. Session 3             7. Session 7
4. Session 4             8. Session 8
```

**After (修复后):**
```text
[视口初始]                [滚轮下滚 4 行]               [鼠标点击视口第 1 行 "Session 5"]
1. Session 1             5. Session 5  <-- 视觉在第 1 行   ✅ 正确选中 "Session 5"
2. Session 2             6. Session 6                     (offset=4 + visible_row=0 = index 4)
3. Session 3             7. Session 7
4. Session 4             8. Session 8
```

### 场景 2：By Tag 模式下「未分类」选中高亮与取消选中 (F3)

**Before (缺陷):**
```text
[未选中]            [选中高亮]          [取消选中移开]
🏷️ 未分类 (1 main) -> [🏷️ 未分类 (1 main)] -> 🏷️ 分类 (1 main)  ❌「未」字永久丢失
```

**After (修复后):**
```text
[未选中]            [选中高亮]          [取消选中移开]
🏷️ 未分类 (1 main) -> [🏷️ 未分类 (1 main)] -> 🏷️ 未分类 (1 main)  ✅「未分类」完整恢复
```
