# Proposal: prd8-phase2-navigation-enhancements

## Intent

本变更解决 PRD-8 规划的 **Phase 2 核心导航体验增强**。在会话树规模不断增长、层级结构深入的场景下，目前的 TUI 导航方式存在以下效率痛点：
1. **长列表纵向穿透慢**：单行步进无法快速跨过大量展开的会话与子代理，缺乏类似 Vim 的大幅纵向跳跃能力。
2. **列表首尾往返成本高**：在滚动到列表末尾或首部时，缺乏循环回绕（wraparound），需长按反向键或多步翻页返回。
3. **节点快速折叠收拢困难**：在深度展开多个分组与多层 Parent-Agent 树后，缺少一键全部收起机制，用户必须手动定位各个父节点并逐一折叠。

通过引入大写 `J`/`K` 步长 5 快速跳跃、小写 `j`/`k` 首尾循环回绕、以及 `z` 一键折叠所有展开节点，大幅提升大规模会话目录下的键盘穿梭与视野归拢效率，同时确保与弹窗、搜索输入等交互上下文的严密隔离。

## Scope

### 包含
- **F4: 大写 J/K 快速移动（步长 5）**
  - 在会话树可见行中，大写 `J`（Shift+j）向下跳转 5 个可见行；大写 `K`（Shift+k）向上跳转 5 个可见行。
  - 到达列表上下边界时平稳停止在首行或末行，不回绕、不循环。
  - 列表行数不足 5 项、单项或空列表时安全处理，不发生越界 panic。
- **F5-1: 小写 j/k 首尾循环回绕**
  - 小写 `j` 处于最后一个可见行时，再次下行循环回绕到第一个可见行。
  - 小写 `k` 处于第一个可见行时，再次上行循环回绕到最后一个可见行。
  - 列表只有 1 项或 0 项时安全保持，不发生死循环或 panic。
- **F5-2: z 一键折叠所有展开节点**
  - 按 `z` 一键折叠所有当前展开的分组（Group）节点和父会话（Parent Session）节点（基于 `tree_state.close_all()`）。
  - 折叠后当前选中项安全降级并定位到其最近的可见祖先节点（如所属 Group 头节点）或首个可见节点，杜绝光标悬空或不可见。
  - 联动刷新概览摘要与右侧面板，保持数据一致性。
- **交互上下文与键位隔离**
  - 所有弹窗模式（删除确认、标签编辑、导出菜单、全文搜索浮层、快捷键帮助）优先拦截键盘输入，严禁泄漏 J/K/z 到会话树列表。
  - 快速搜索输入模式（`/`）：输入大写 J/K 或 z 视为正常搜索字符追加，不触发树导航或折叠。
  - 快捷键帮助弹窗（`?`）：更新展示 J/K（步长 5 跳转）与 z（一键折叠）的快捷键说明。

### 不包含（严格 Non-Goals）
- 严禁引入或预埋 PRD-8 Phase 3 功能：
  - 顶栏右侧 Group-by 鼠标切换按钮与样式排版。
  - Group-by 模式选择持久化到 `state.db`。
  - 顶栏引擎 Tab 鼠标左键点击切换引擎。
  - 全文搜索结果列表卡片排版、分割线、方向键选中高亮底色重构。
- 不修改底层搜索索引或检索逻辑。
- 不变更 `state.db` schema 或 SQLite 表结构。
- 不引入新的第三方依赖或修改 `Cargo.toml`。

## Affected Domains

- **System Spec domain**：
  - `tui-interaction`: 增强会话树导航契约，补充 J/K 步长 5 快速跳跃、j/k 边界循环遍历、z 一键折叠与选中祖先保留，以及帮助弹窗和输入隔离契约。
- **代码/数据/外部系统影响**：
  - `src/app.rs`: 扩展 `handle_key` 与导航定位逻辑，支持 J/K/z 处理、循环回绕与折叠收缩；维持模态弹窗与搜索输入优先拦截。
  - `src/tui.rs`: 更新快捷键帮助弹窗（`?`）文字，增加 J/K 与 z 说明。
  - 不涉及数据持久化或外部依赖。

## Design Impact

- 档位：visual
- 影响面（窗口/组件/状态）：
  - 会话树列表光标快速定位与循环移动
  - 会话树一键折叠（z）视觉状态切换与选中收缩
  - 快捷键帮助弹窗（?）追加 J/K 与 z 说明
- 证据路径：ux-design.md

## Success Criteria

- [ ] 大写 `J`（Shift+j）在会话树中向下移动 5 行并加载详情；末尾不足 5 行时平稳停在最后一行，不回绕。
- [ ] 大写 `K`（Shift+k）在会话树中向上移动 5 行并加载详情；首部不足 5 行时平稳停在第一行，不回绕。
- [ ] 小写 `j` 在最后一个可见行时按下，光标平滑回到第一个可见行并加载对应详情。
- [ ] 小写 `k` 在第一个可见行时按下，光标平滑跳到最后一个可见行并加载对应详情。
- [ ] 当列表中只有 1 项或 0 项时，按 `J`、`K`、`j`、`k` 均平稳安全，不崩溃、不死循环。
- [ ] 按 `z` 一键收起所有展开的组与父会话，可见行紧凑收敛至顶层组，原选中项安全保留在对应组节点或首节点。
- [ ] 在 `/` 快速搜索输入中输入 `J`、`K`、`z` 时作为字符输入进入搜索词，不触发任何跳转或折叠。
- [ ] 在删除弹窗、标签弹窗、导出弹窗、全文搜索弹窗、帮助弹窗中，按 `J`、`K`、`z` 不泄露到底层会话树。
- [ ] 按 `?` 打开的帮助弹窗中清晰展示 `J / K` 与 `z` 的功能说明。
