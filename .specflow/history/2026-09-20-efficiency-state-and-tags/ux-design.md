# UX Design: efficiency-state-and-tags

## Design Impact

- 档位：`visual`（增加弹窗交互、树行状态图标、标签徽标、分组模式视觉扩展）
- 关联宪章条目：
  - 维持双栏紧凑骨架，不增加割裂的第三栏或冗余面板。
  - 遵循终端可用性原则：浮层居中自适应、窄终端平滑截断不破坏边界、快捷键流转明确。

## 视觉意图

- **一句话目标**：在不破坏现有经典双栏与树状导航的前提下，以最直观的星标与徽标呈现收藏与标签，提供与删除弹窗同等纯粹的标签编辑体验，并赋予用户按标签分组与前缀过滤会话的高效能力。
- **与现状的差异**：
  - 会话列表：未收藏不占位保持紧凑，收藏时前置醒目黄/金色 `★`；摘要末尾追加弱化灰色 `#tag1 #tag2`。
  - 弹窗系统：新增居中 Edit Tags 弹窗（与 Delete Modal 一致的圆角浮层和按钮聚焦样式）。
  - 分组系统：新增 `🏷️` 标签分组维度，支持未分类汇聚与多标签并行展示。
  - 搜索栏：支持 `fav:` 与 `tag:` 引导前缀，实时反馈匹配数。

## 受影响表面

1. **左侧 Session Tree 节点行**：
   - 主会话叶子节点：增加 `★` 前缀和 `#tags` 徽标。
   - 子代理节点：保持简洁，不显示收藏星标与标签徽标。
2. **分组标题（Group Header）**：
   - 新增 `GroupMode::ByTag` 模式下的 `🏷️ {tag_name} ({root_count} main · {sub_count} sub)` 样式。
3. **标签编辑弹窗（Tag Modal）**：
   - 居中覆盖层，提供会话 ID、标签输入框、光标下划线、清空提示及 Cancel/Save 按钮组。
4. **底部状态栏与搜索输入行**：
   - 搜索输入激活时，占位提示丰富为包含 `fav:` / `tag:` 语法的指导文本；遇到写入失败时展示醒目权限警告。
5. **帮助浮层（Help Modal）**：
   - 增加 `f` (Toggle favorite) 与 `t` (Edit tags) 键位说明。

### 3. 标签编辑弹窗线框 (Edit Tags Modal)

尺寸：宽度 64~72 列，高度 9 行，水平垂直双向居中。
```text
╭ Edit Tags ──────────────────────────────────────────────────────╮
│                                                                  │
│  Session: 019ff00e-623f-7018-8d1d...                            │
│                                                                  │
│  Tags (comma separated):                                        │
│  bug, urgent_                                                   │
│                                                                  │
│  (Leave empty to clear all tags)                                │
│                    [ Cancel ]      Save                          │
╰──────────────────────────────────────────────────────────────────╯
```

- **光标表示**：输入激活时，文本末尾以 `_` 或反显字符表示光标位置。
- **按钮样式**：
  - 聚焦状态：`[ Cancel ]` 或 `[ Save ]`，高亮前景色；
  - 非聚焦状态：弱化色无外括号。

### 4. 交互状态流转与键位契约

```text
[主列表 / 选中叶子]
   │
   ├─ 按 'f' ─────────► 即时切换 is_favorite，写入 state.db，刷新星标
   │
   ├─ 按 't' ─────────► 打开 TagModalState，预填已有标签，光标置于末尾
   │                        │
   │                        ├─ 可打印字符 / Backspace ──► 编辑标签文本
   │                        ├─ Tab / Left / Right ──────► 焦点循环: Input ↔ Cancel ↔ Save
   │                        ├─ Enter (Input 或 Save) ──► 规范化清洗，写入 state.db，关闭弹窗，刷新徽标
   │                        ├─ Enter (Cancel) / Esc ────► 放弃修改，关闭弹窗
   │                        └─ 输入清空提交 ────────────► 清空该会话所有标签
   │
   ├─ 按 'g' ─────────► By Time → By Project → By Tag → By Time 循环切换
   │
   └─ 按 '/' ─────────► 进入搜索输入模式:
                            ├─ 输入 "fav:" ─────────────► 仅匹配收藏会话
                            ├─ 输入 "tag:bug" ──────────► 仅匹配含 bug 标签会话
                            └─ 输入 "tag:bug login" ────► 组合过滤
```

## 与宪章的符合性

1. **一致性（Consistency）**：弹窗边框、按钮焦点、阴影和按键行为与既有 `DeleteModalState` 保持百分之百的模式对齐。
2. **非侵入性（Non-intrusiveness）**：未收藏会话不强制填充空格，标签弱化颜色尾置，不挤占会话标题的核心可读性。
3. **鲁棒性（Robustness）**：在超窄终端（宽 < 80 列）下，后置标签徽标自动截断折叠，优先保障会话标题与星标的完整性。
4. **即时反馈（Immediate Feedback）**：'f' 键一键标记无延迟交互，写入失败（如权限不足）由状态栏醒目告警。

## 验收提示（给 QA）

- **视觉焦点校验**：
  - 验证 `f` 触发时星标 `★` 的出现与隐藏是否无闪烁，重启后是否依然正确渲染。
  - 验证子代理节点（`↳ Subagent`）绝对不出现收藏星标或标签。
- **弹窗交互校验**：
  - 验证逗号分隔输入（如 `"bug,  feature, , bug "`）在保存后是否正确清洗为去重、无空格的 `#bug #feature`。
  - 验证输入清空提交后，标签徽标是否被彻底清除。
  - 验证 `Esc` 取消后，原标签完好无损。
- **搜索与分组校验**：
  - 验证 `/` 输入 `fav:`、`tag:xxx` 及组合关键字时，匹配行数计数器是否精准更新。
  - 验证 `g` 键切至 `By Tag` 时，多标签会话是否在每个对应标签下均能正确展开和选中。
- **异常恢复校验**：
  - 模拟只读 `~/.session-manager/state.db`，检查状态栏是否显示明确错误提示，且界面不卡死。
