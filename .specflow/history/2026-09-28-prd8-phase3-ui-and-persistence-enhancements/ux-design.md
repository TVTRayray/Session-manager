# UX Design: prd8-phase3-ui-and-persistence-enhancements

## Design Impact

- **档位**：`visual`
- **关联宪章条目**：
  - 终端原生直觉（Terminal Native Affordances）：所有界面元素使用标准 Unicode/ASCII 字符与确定性列对齐，纯终端瞬时重绘，无动画过渡。
  - 色彩与排版（Catppuccin Mocha Theme Tokens）：严格沿用既有色彩常数（`THEME_*`），提供暗色/高亮可读性实际截图与取色测试计划。
  - 状态与尺寸完整性（State & Dimension Matrix）：覆盖查询为空、加载中、空结果、FTS5 禁用、部分索引、查询错误、选中/未选中卡片、焦点恢复、鼠标与键盘交互，以及从基准 130×40 到极窄 0/1/2 宽度的行为策略。

## 视觉意图

- **本次变更要达成的视觉/体验目标**：
  在保持 Catppuccin Mocha 终端质感的前提下，为顶栏补充动态计算对齐的右侧 Group-by 按钮与鼠标点击交互，并重构全文搜索浮层为卡片底色清晰、间隔明确、选中全卡片强调的高可读性列表。
- **与现状的差异**：
  - **顶栏（Header）**：目前仅有左侧四个引擎 Tab，右侧缺乏分组操作入口；优化后右侧呈现与左侧 Tab 视觉统一的 `By Time | By Project | By Tag` 切换组，高亮反映当前模式，鼠标可直接点击任一 Tab 或 Group-by 按钮。
  - **搜索浮层（Full-text Search Overlay）**：目前搜索结果平铺无底色区分，仅靠 `▸` 指示焦点；优化后每条结果以独立卡片呈现，卡片之间有水平分隔线，选中项整行/整卡片获得对比底色与加粗强调，关键词高亮继续醒目可读。

## 受影响表面

- **窗口/组件/状态列表**：
  1. 顶栏（Row 0）：左侧引擎 Tab（Pi / OpenCode / Codex / Claude）、右侧 Group-by 模式组（By Time / By Project / By Tag）、分隔符（` | `）、中间弹性空格。
  2. 搜索浮层（`Ctrl+F` 弹窗）：结果卡片容器、未选中卡片、选中卡片、相邻卡片分隔线、高亮关键词片段、状态说明行。
- **是否动 tokens**：否。严格使用既有 `THEME_*` 常量，不新增、不修改 token。

## 终端尺寸适配与裁剪策略

顶栏左右布局不锁死固定常数，而是复用 `src/tui.rs` 现有的 `display_width` / `to_char_clusters` 计算真实列宽（不引入外部依赖）进行动态判定：
- **左侧引擎 Tabs 宽度**（`left_w`）：遍历实际渲染的引擎 Tab 文本与分隔符 `" | "` 动态累加其显示宽度。
- **右侧 Group-by 按钮宽度**（`right_w`）：遍历实际渲染的各个模式按钮文本与分隔符 `" | "` 动态累加其显示宽度。
- **最小安全间距**（`min_gap`）：至少保留 1 列空格，避免双侧文字紧贴。
- **动态容纳阈值**：`threshold = left_w + min_gap + right_w`，由布局渲染时动态求和计算，通过边界测试（刚好可容纳、刚好碰撞、极端窄屏）保证两端安全对齐。

| 终端尺寸 | 布局表现与裁剪/禁点策略 |
| :--- | :--- |
| **130 × 40（基准尺寸）** | 宽度充裕（远大于阈值），左侧引擎 Tab 靠左、右侧 Group-by 按钮靠右，中间自适应留白。左右两侧鼠标 Hitbox 均精准有效。 |
| **80 × 24（标准终端）** | 可用宽度（80 列）小于完整容纳所需宽度。按动态宽度判定，优先完整保障左侧核心引擎 Tab；右侧 Group-by 区域进行安全裁剪或隐藏。右侧 Hitbox 自动禁用，防止左侧与右侧重叠误触。 |
| **40 × 12（紧凑终端）** | 空间极其受限。右侧 Group-by 按钮完全隐藏，左侧引擎 Tab 按照标准截断逻辑渲染。右侧鼠标点击完全忽略，左侧仅在完整显示的 Tab 范围内可点。 |
| **极窄边界（0、1、2 列）** | 终端极度窄缩边界。渲染函数安全裁剪为 0 长度或受限字符，绝对不发生负数切片或 underflow panic；所有鼠标点击事件安全忽略。 |

## 完整状态矩阵覆盖

| 状态类型 | 触发条件 | 界面表现 | 焦点与导航行为 |
| :--- | :--- | :--- | :--- |
| **查询为空** | 搜索输入为空或仅空格 (`query.trim().is_empty()`) | 居中提示 `Type keywords to search session transcripts...` | 光标停在输入框，按 Esc 关闭浮层并恢复原列表焦点 |
| **搜索加载中** | 查询防抖中或后台搜索执行中 (`is_loading`) | 居中弱化提示 `搜索中...` | 不响应结果选择，不闪烁残余结果 |
| **搜索无结果** | 查询完成但无匹配记录 (`results.is_empty()`) | 居中提示 `No matching sessions found.` | 方向键无卡片可移动，按 Esc 正常退出浮层 |
| **FTS5 禁用** | 数据库环境缺少 FTS5 组件 (`!is_ready()`) | 居中黄色警告 `⚠️ 全文搜索不可用：当前 SQLite 环境未启用 FTS5 扩展组件` | 明确告知用户环境限制，输入不报错 |
| **部分/陈旧索引** | 后台索引构建中 (`!progress.is_complete`) | 底部状态行提示 `⚠️ 索引构建中 (N/M)，搜索结果基于已完成部分` | 允许查看和导航基于已索引部分返回的结果卡片 |
| **查询错误** | 检索发生非预期错误 (`error_message`) | 居中黄色警告 `⚠️ {error_message}` | 错误提示可见，按 Esc 退出恢复主窗口 |
| **卡片选中/未选中** | 结果列表中光标上下移动 | 选中卡片整行反衬强调；非选中卡片保持微弱底色与横线分隔 | 方向键 ↑/↓ 瞬时切换高亮卡片，移开即复原 |
| **鼠标与键盘交互** | 键盘 Tab / 鼠标点击顶栏 Tab | 切换引擎并清空陈旧选区/详情；点击 Group-by 即刻持久化 | 键盘与鼠标互不干扰，未持久化时状态栏明确告警 |

## 主题色彩与对比度测试计划

本变更严格沿用既有 Catppuccin Mocha 色彩常量，不引入未经验证的硬编码颜色：
- `THEME_BG`: `#181825`（Base）
- `THEME_HEADER_BG`: `#1E1E2E`（Mantle）
- `THEME_BORDER`: `#585B70`（Surface2）
- `THEME_HIGHLIGHT`: `#89B4FA`（Blue）
- `THEME_TEXT`: `#CDD6F4`（Text）
- `THEME_SEARCH_BG`: `#F9E2AF`（Yellow）
- `THEME_SEARCH_FG`: `#181825`（Base）

**实际色彩对比度与可读性测量方案**：
1. **真实截图取色**：在 QA/实施验收阶段，于真实终端（Kitty / Ghostty / WezTerm）截取正常光照与暗色环境下的实际渲染截图。
2. **取色比对与验证**：使用取色工具测量正文 `THEME_TEXT` 对背景 `THEME_HEADER_BG`、以及搜索关键词 `THEME_SEARCH_FG` 对 `THEME_SEARCH_BG` 的实际 RGB 值，计算其实际对比度并记录在测试报告中，不作无依据的主观声明。
3. **视觉可读性核查**：确认在强调卡片背景与黄色关键词叠加时无模糊或变色，确保夜间和高对比度终端模式下的清晰度。

## 验收提示（给 QA）

1. **顶栏引擎切换**：用鼠标左键逐个点击 `Pi`、`OpenCode`、`Codex`、`Claude`，核对会话树是否即时刷新，陈旧的选区与详情是否清空，与 `Tab` 键是否完全一致。
2. **顶栏 Group-by 切换与持久化**：
   - 用鼠标分别点击 `By Project` 和 `By Tag`，观察会话树是否重新分组、按钮高亮是否移动。
   - 在 `By Project` 模式下退出应用并重启，确认重启后首屏是否保持为 `By Project`。
   - 使用键盘 `g` 切换到 `By Tag` 并退出重启，确认键盘切换也成功持久化。
3. **动态宽度裁剪与禁点**：
   - 刚好可容纳：将终端调整至略大于阈值宽度，观察两端对齐且点击均生效。
   - 刚好碰撞：将终端宽度缩窄至刚好无法完整容纳右侧按钮，核验右侧按钮被安全裁剪/隐藏，右侧点击区域完全失效，无字符重叠碰撞。
   - 极窄测试：在 40×12 及极窄宽度下操作，验证无 panic。
4. **搜索结果排版与导航**：
   - 按 `Ctrl+F` 验证空查询提示。
   - 输入关键词，观察结果是否带卡片底色与分隔线。
   - 按 ↓ 和 ↑ 键在结果之间移动，核对选中项整行高亮是否明显突出，移开后是否瞬时复原。
   - 检查 `«关键词»` 高亮块在选中和非选中卡片中均清晰无错位。
